# IMCP — entregáveis

Este repositório contém:

- **index.html** — mockup visual e interativo, autocontido e pronto para publicação estática no Netlify.
- **IMCP_Proposta_Solucao.doc** — documento compatível com Microsoft Word, contendo o entendimento do processo, AS IS, TO BE, arquitetura, escopo da Fase 1, Fase 2 e investimentos além do desenvolvimento.

## Publicar o mockup no Netlify

1. Baixe o arquivo `index.html`.
2. Coloque-o dentro de uma pasta vazia.
3. No Netlify, use **Add new site > Deploy manually**.
4. Arraste a pasta para a área de upload.

O mockup não depende de backend e pode ser publicado como site estático.
